developers

seedless labs builds open-source tools on solana for apps that move real money for normal people: passkey sign-in with no seed phrase, sponsored gas, spending rules for ai agents, and payouts to bank accounts.

quickstart

two ways in. each runs on solana devnet and takes a few minutes.

1. passkey-dwallet-controller: typecheck the client (no solana tooling needed)

you need node 20+.

git clone https://github.com/seedless-labs/passkey-dwallet-controller
cd passkey-dwallet-controller/client
npm ci
npm run typecheck

building the program itself also needs ika-pre-alpha and solana platform-tools. the readme has the steps.

2. leash: give an ai agent a vault it can't overspend

you need node 20+, pnpm, the solana cli and a little devnet sol.

git clone https://github.com/seedless-labs/leash
cd leash
pnpm install

# make the keys (gitignored), fund the fees wallet on devnet
mkdir -p .keys
for k in owner agent fees vendor-1 vendor-2 vendor-3 decoy-1 decoy-2; do
  solana-keygen new --no-bip39-passphrase -s -o .keys/$k.json
done
solana airdrop 1 $(solana-keygen pubkey .keys/fees.json) --url devnet

# create your own vault with a spending limit, then prove the rules hold
npx tsx scripts/setup.ts
npx tsx scripts/prove.ts

# run the app with a scripted model, no api key needed
LEASH_MOCK_MODEL=1 pnpm dev

open http://localhost:3000 and watch the vault refuse payments outside its rules.

open-source repos

  • leash (typescript): ai agent spending from a squads v4 vault, under on-chain rules the agent can't change.
  • leash-pay (typescript): an ai agent pays invoices through paypal behind a policy gate: caps, approvals, kill switch, mcp server.
  • strom (typescript): move usdc and sol from solana to near in one signature, no gas token needed.
  • hermes-money-rules (python): pay, split, sweep and alert on stablecoins from your own solana wallet, under a usdc cap you sign. gasless.
  • passkey-dwallet-controller (rust): a solana program that lets a webauthn passkey control an ika mpc dwallet and approve cross-chain signatures.
  • deadcheque (typescript): post-dated cheques on solana: write it, print it, it pays itself on the date.
  • mermail-settle-to-bank (skill): pay an approved bank beneficiary from an agent wallet. email can trigger a payout, never name where it goes.

everything lives at github.com/seedless-labs.

what we build with

  • languages: typescript, rust, python
  • solana: pinocchio and anchor programs, @solana/web3.js, squads v4, kora for sponsored gas, secp256r1 passkey verification, mollusk for program tests
  • apps: react native and expo on ios and android, webauthn passkeys
  • backend: cloudflare workers and d1
